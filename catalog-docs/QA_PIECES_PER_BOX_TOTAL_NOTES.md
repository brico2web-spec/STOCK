# QA — قطع داخل العلبة ومجموع القطع

| الاختبار | النتيجة |
|---|---|
| أعمدة تفاصيل الكوموند | أصبحت: المنتوج، العلب، قطع/علبة، مجموع القطع، الثمن، المجموع. |
| عدد القطع داخل العلبة | يُقرأ من `row.units` أو `product.qty`، ويظهر مثلًا 20 قطعة/علبة. |
| مجموع القطع | يُحسب من `paidUnits` ويظهر مثلًا 3 علب × 20 = 60 قطعة. |
| صورة Bon de commande | تعرض الأعمدة الستة نفسها داخل جدول الصورة. |
| الحساب المؤقت | كوموند بـ3 علب و20 قطعة/علبة أظهرت 60 في مجموع القطع. |
| اتجاه الصورة | بقي `direction: rtl` و`text-align: right`. |
| كود الطلبية | بقي ظاهرًا من `order.orderCode` في رأس الصورة. |
| الأرقام الحمراء | لم يتم تغييرها؛ هي علامات شرح خارج التطبيق كما وضح المستخدم. |
| سلامة البيانات | استُعملت كوموند مؤقتة ولم تُحفظ في localStorage. |
| الفحص البرمجي | مرّ `node --check app.js` بنجاح. |
