
# QA — صفحة رجوع السلع

تم تحميل النسخة الأخيرة على شاشة الهاتف بنجاح، وظهرت الأسعار بصيغة درهم. تمت إضافة زر `رجوع السلع` داخل قسم `إدارة المنتوجات` ونافذة مستقلة تجمع الإرجاعات المحفوظة من البونات. سيتم الآن اختبار التجميع المؤقت والبحث والعرض دون تغيير بيانات المستخدم.

## الاختبار المؤقت الناجح

تم اختبار بونين مؤقتين في الذاكرة فقط: كليان `DRG HASSAN` بإرجاع قطعتين، وكليان `AMAL` بإرجاع قطعة واحدة. ظهرت الصفحة مفتوحة، وعدّاد الكليان `2`، العمليات `2`، القطع `3`، والمجموع `90,00 درهم`. ظهر اسم المنتوج والكود ورقم البون وسطر الحساب بصيغة واضحة `2 قطعة × الثمن = المجموع`. البحث باسم `HASSAN` أخفى كليان `AMAL` وأبقى السجل المطابق. تمت إعادة الطلبات و`localStorage` إلى الحالة الأصلية بعد الاختبار.
