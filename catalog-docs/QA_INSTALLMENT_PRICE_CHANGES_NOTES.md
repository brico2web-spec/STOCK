# QA — الأقساط وتغييرات الأثمنة

## نطاق التعديل
تمت إضافة قسم اختياري داخل نموذج **تسجيل قسط جديد** يسمح باختيار منتوج، عرض الثمن القديم، إدخال الثمن الجديد، وحساب فرق التغيير مباشرة. عند الحفظ يتم تخزين التغيير داخل الطلب في الحقل `priceChanges` مع اسم المنتوج والكود والثمنين والتاريخ.

تمت إعادة تنظيم نافذة **تتبع المستخلاصات** لتعرض فقط العمليات المرتبطة بالأقساط وتغييرات الأثمنة، مجمعة في بطاقة مستقلة لكل كليان. كل بطاقة تعرض مجموع أقساط الكليان وقيمة تغييرات الأثمنة وتفاصيل العمليات.

## الاختبارات المنجزة

| الاختبار | النتيجة |
|---|---|
| فحص صياغة `app.js` | ناجح عبر `node --check app.js` |
| فحص صياغة `ai-agent-reports.js` | ناجح عبر `node --check ai-agent-reports.js` |
| فتح نموذج تسجيل قسط جديد | ناجح داخل المتصفح |
| ظهور زر إضافة تغيير ثمن | ناجح |
| ظهور اختيار المنتوج والثمن القديم والجديد | ناجح |
| الحساب المباشر لفرق الثمن | ناجح؛ مثال 30.00 إلى 28.00 أعطى 2.00 DH |
| تجميع الكليان في بطاقات مستقلة | ناجح باختبار مؤقت دون حفظ بيانات المستخدم |
| عرض مجموع الأقساط وتغييرات الأثمنة لكل كليان | ناجح باختبار DOM مؤقت |
| عدم تغيير بيانات المستخدم أثناء الاختبار | محفوظ؛ تم استعمال بيانات مؤقتة في الذاكرة فقط |
| تجاوب الواجهة على الهاتف | تمت معاينته داخل نافذة الهاتف، والخانات تلتف عموديًا في الشاشات الصغيرة |

## ملاحظات التوافق
تم الحفاظ على مفاتيح التخزين الحالية، وإضافة `priceChanges` داخل الطلبات فقط عند تسجيل تغيير ثمن. لا يتم حذف سجل الأقساط أو بيانات الطلبات القديمة، كما تبقى الدورات المؤرشفة قابلة للعرض مع القيم المتوفرة فيها.
