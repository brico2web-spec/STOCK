
# QA — نظام الإرجاعات / Retours

## بدء الاختبار — 16/08/2026

تم تحميل النسخة الجديدة وفحص الصياغة. الكوموندات الموجودة في بيئة الاختبار الحالية ما فيهاش أسطر منتجات، لذلك سيُستعمل طلب مؤقت داخل الذاكرة فقط لاختبار إدخال كود المنتوج، حساب القطع والثمن، طرح الإرجاع، وصورة البون. لن يتم حفظ بيانات الاختبار في `localStorage`.

## الاختبارات الناجحة

تم اختبار كود `AC40` مع منتوج ثمنه `30 DH` وعدد `2` قطع. ظهرت المعاينة باسم المنتوج، الكود، الثمن، القطع المطلوبة، القطع المتبقية للإرجاع، وقيمة `−60 DH`. بعد الحفظ المؤقت صار مجموع البون والباقي أقل بـ `60 DH`، وتخزّن سجل إرجاع واحد، ثم تمت إعادة بيانات الطلبات الأصلية.

تم اعتراض إنشاء الصور في الذاكرة فقط. ظهرت خانة `الإرجاعات / Retours` في صورة Bon de commande وصورة العملية، مع الكود والثمن والقطع والمبلغ، وظهرت الألوان الخضراء المطلوبة. لم يتم حفظ بيانات الاختبار في `localStorage`.

## اختبار عدم وجود الإرجاع

تم إنشاء صورة Bon de commande مؤقتة بطلبية فيها `returns: []`. لم يظهر فيها قسم `الإرجاعات / Retours` ولا أي مبلغ إرجاع، كما هو مطلوب.
