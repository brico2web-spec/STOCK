
# QA — Remise فصفحة تفاصيل الكوموند

## المرحلة الأولى — 16/08/2026

تم تحميل النسخة الجديدة وفتح أرشيف الطلبيات ثم صفحة تفاصيل كوموند على شاشة الهاتف. تفتحات الصفحة بلا أخطاء وبقي قسم الأقساط ظاهرًا. الكوموند التجريبية المفتوحة ما فيها حتى سجل Remise، لذلك بقي قسم التخفيض مخفيًا كما هو مطلوب.

سيتم الآن اختبار ظهور القسم باستعمال تخفيض مؤقت داخل الذاكرة فقط، ثم إرجاع الطلبية الأصلية.
