# QA — كود الطلبية وتجميع تغييرات الأثمنة واتجاه الصورة

| الاختبار | النتيجة |
|---|---|
| خانة كود الطلبية في نموذج التسجيل | موجودة بالمعرف `orderCode` وتقبل كودًا يكتبه المستخدم. |
| حفظ الكود | يُحفظ داخل `order.orderCode` مع استعمال `order.id` كبديل للسجلات القديمة. |
| ظهور الكود في Bon de commande | يظهر في رأس الصورة داخل خانة **N. Bon Commande** وفي بطاقة معلومات الكوموند. |
| تجميع تغييرات الأثمنة | ثلاث سجلات متكررة لنفس المنتوج تُعرض كسجل واحد فقط في تفاصيل الكوموند والصورة. |
| الثمن المتغير | يحتفظ بأول ثمن أصلي وآخر ثمن جديد ويحسب الأثر حسب الكمية. |
| اتجاه صورة Bon de commande | اختبار DOM المحسوب أعاد `direction: rtl` و`text-align: right`. |
| المعلومات داخل الصورة | بقيت المنتجات، الأقساط، تغييرات الأثمنة، Total payé، الباقي، وعبارة التحقق واضحة. |
| سلامة البيانات | الاختبار استعمل كوموندات مؤقتة وأعاد مصفوفة الطلبات كما كانت دون حفظ. |
| JavaScript والمهارة | تم تمرير `node --check app.js` وفحص المهارة عبر `quick_validate.py`. |
