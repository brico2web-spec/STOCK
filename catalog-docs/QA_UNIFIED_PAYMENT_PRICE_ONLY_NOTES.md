# QA — زر الحفظ والإرسال وتغيير الثمن فقط

## التغييرات المطبقة

تم حذف أزرار **حفظ القسط** و**إرسال ملخص الزبون** و**إرسال صورة العملية** من أسفل النموذج، واستبدالها بزر واحد باسم **حفظ وإرسال للزبون**. الزر يحفظ العملية ثم يجهز صورة العملية للمشاركة عبر الهاتف.

تمت إضافة وضع **تغيير الأثمنة فقط بدون تسجيل قسط**. في هذا الوضع يصبح مبلغ القسط غير مفعل، ويمكن حفظ تغيير ثمن منتوج بدون إضافة سجل أداء أو تغيير مجموع الأقساط.

تم حصر قائمة المنتوجات في تغيير الأثمنة على العناصر الموجودة داخل كوموند الكليان، مع مطابقة إضافية بالمعرف أو الكود أو الاسم لدعم الطلبات القديمة.

## الاختبارات المنجزة

| الاختبار | النتيجة |
|---|---|
| فحص `app.js` | ناجح عبر `node --check app.js` |
| فحص `ai-agent-reports.js` | ناجح عبر `node --check ai-agent-reports.js` |
| وجود زر واحد للحفظ داخل النموذج | ناجح؛ زر `paymentSaveShareBtn` فقط |
| اختفاء الزرين القديمين | ناجح؛ لا توجد مراجع `paymentCustomerBtn` أو `paymentImageBtn` |
| تفعيل وضع تغيير الثمن فقط | ناجح؛ مبلغ القسط يصبح معطلًا وغير إجباري |
| حصر المنتوجات في الكوموند | ناجح باختبار مؤقت؛ ظهر منتوج الكوموند فقط في القائمة |
| حفظ تغيير الثمن بدون قسط | ناجح باختبار مؤقت؛ تمت إضافة تغيير الثمن دون زيادة عدد الأقساط |
| صورة المشاركة بدون قسط | ناجح باختبار مشاركة وهمية؛ تم إنشاء ملف JPEG بحجم تقريبي 123540 بايت |
| استرجاع بيانات الاختبار | ناجح؛ لم يتم حفظ بيانات الاختبار في `localStorage` |
| الكوموند المخلصة بالكامل | تفتح النافذة تلقائيًا في وضع تغيير الثمن فقط |
| توافق الهاتف | تمت معاينة الواجهة داخل متصفح الهاتف، والزر الموحد بعرض كامل |
