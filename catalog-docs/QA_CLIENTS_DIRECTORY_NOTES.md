# QA — صفحة الزبناء

تم فحص النسخة المحلية بتاريخ 2026-08-14.

ظهر داخل نافذة «إضافة معلومات الكليان» زر جديد بعنوان «الزبناء» فوق زر «كشف الزبناء والإحصائيات». عند الضغط عليه ظهرت نافذة مستقلة بعنوان «الزبناء» تحتوي على عداد الزبناء، خانة بحث سريع بالاسم أو الشركة أو ICE، وزر إغلاق.

تحتوي الصفحة الجديدة على قائمة بطاقات الزبناء عند توفر البيانات، وكل بطاقة مرتبطة بزر «Infos facturation» لاستدعاء إرسال معلومات الفوترة PDF، وزر «تعديل» لفتح نموذج الزبون مع بياناته وتحديثها. فحص `node --check app.js` نجح.

كانت جلسة الاختبار الحالية بلا زبناء محفوظين، لذلك ظهر العداد 0 ورسالة القائمة الفارغة، بينما تأكد ظهور الصفحة وعناصر البحث والتفاعل الأساسية.
