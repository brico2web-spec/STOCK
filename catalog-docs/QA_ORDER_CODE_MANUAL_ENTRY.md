# QA — رقم البون فارغ حتى الإدخال اليدوي

## التعديل
الكوموند الجديدة تُحفظ بـ `orderCode: ""`. صور Bon de commande وصور عمليات القسط تستعمل `order.orderCode || ""` بدل السقوط إلى `order.id`، لذلك لا يظهر UUID أو رقم تلقائي.

## الاختبار الأول
تم توليد صورة بكوموند تجريبية و`orderCode` فارغ. ظهر صندوق `N. Bon Commande` فارغًا بدون أي رقم أو معرف تلقائي.

## الاختبار التالي
تم توليد صورة ثانية بنفس الكوموند بعد تعيين `orderCode` يدويًا إلى `BON-MANUAL-001`، وسيتم فحصها بصريًا للتأكد من ظهوره.

## نتيجة الاختبار
بعد تعيين `orderCode` إلى `BON-MANUAL-001` ظهر الرقم في خانة `N. Bon Commande` أعلى الصورة. النتيجة تؤكد أن الخانة تكون فارغة للكوموند الجديدة وتظهر فقط بعد إدخال الرقم يدويًا وحفظ العملية.
