
# QA — حذف زر تسجيل القسط ورقم البون

تم تحميل النسخة الجديدة على واجهة الهاتف بنجاح. أزيل زر `تسجيل قسط` من بطاقة أرشيف الكوموندات على مستوى القالب والمنطق، وأضيف محرر رقم البون داخل صفحة تفاصيل الكوموند لحفظه وإعادة استعماله في صور Bon de commande وصورة العملية.

سيتم اختبار DOM ومسار الحفظ والصور ببيانات طلبية مؤقتة فقط، مع استرجاع البيانات الأصلية بعد الاختبار.

## الاختبارات الناجحة

ببيانات كوموند مؤقتة، لم يعد يظهر أي عنصر `data-order-pay` أو زر `payment-btn` داخل بطاقة الأرشيف، بينما بقي زر إرسال الكوموند ظاهرًا.

ظهر محرر `رقم البون / N. Bon Commande` داخل صفحة التفاصيل. بعد إدخال `202326` والضغط على حفظ، تسجل الرقم في الطلبية وظهر في الحقل بعد إعادة فتح التفاصيل.

تم اعتراض توليد الصور مؤقتًا بدون إرسال أو تنزيل فعلي. نجحت صورة Bon de commande وصورة العملية، وظهر الرقم `202326` داخل الصورتين. تمت إعادة الطلبات و`localStorage` إلى الحالة الأصلية.
