# QA — زر البون خالص

تم تعديل تفاصيل الكوموند بحيث يتغير الزر حسب الباقي المحسوب.

| الحالة | النتيجة |
|---|---|
| كوموند فيها باقي أكبر من صفر | يظهر زر `💰 إدخال ثمن القسط / أداء`، ويبقى زر إعادة إرسال الصورة ظاهرًا. |
| كوموند مكتملة الأداء | يظهر زر أخضر `✓ البون خالص` معطّل، ولا يظهر زر إدخال القسط. |
| إعادة إرسال الصورة | يبقى زر `🖼️ إعادة إرسال الصورة للزبون` ظاهرًا في الحالتين. |
| اختبار البيانات | تم استعمال كوموند مؤقتة داخل الذاكرة فقط، بمجموع 1,000 DH وقسط 1,000 DH، فكان `due=0` وظهر زر البون خالص. حُذفت بيانات الاختبار مباشرة ولم تُحفظ في localStorage. |
| الصياغة | اجتاز `app.js` فحص `node --check`. |
