# QA — حذف Clients enregistrés

تم فحص النسخة المحلية بتاريخ 2026-08-14.

ظهرت نافذة معلومات الزبناء دون عنوان أو خانة أو قائمة `Clients enregistrés` القديمة في الأسفل. بقي زر `الزبناء` الجديد فوق زر `كشف الزبناء والإحصائيات`، وبقيت أزرار توقعات المبيعات ورفع ملف الزبناء والتصدير كما هي.

نجح فحص `node --check app.js`، ونجحت أداة التحقق من المهارة `3d-peintures-catalog-workflow`. لم تبقَ مراجع HTML أو JavaScript للعناصر المحذوفة أو للدالة القديمة `renderClientsManager`.
