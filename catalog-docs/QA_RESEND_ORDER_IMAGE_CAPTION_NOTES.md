# QA — إعادة إرسال صورة Bon de commande

## التغييرات المختبرة

| العنصر | النتيجة |
|---|---|
| عنوان الصورة | يظهر **N. Bon Commande** في أعلى الصورة. |
| رقم الكوموند | يظهر في خانة علوية واضحة من قيمة `order.id`. |
| صورة Bon de commande | تُنشأ كـ JPEG بدل مسار PDF عند الإرسال. |
| تغييرات الأثمنة | يظهر الثمن الأصلي بخط يتوسطه، والثمن الجديد، والكمية، والأثر المحسوب. |
| Total payé والباقي | يعتمدان على الإجمالي المعدل بعد تغييرات الأثمنة. |
| سجل الأقساط | يبقى ظاهرًا داخل الصورة مع كل الأقساط السابقة. |
| عبارة الصورة | تظهر أسفل الصورة: **المرجو تحقق من المعلومات.** |
| زر إعادة الإرسال | يظهر داخل تفاصيل الكوموند باسم **🖼️ إعادة إرسال الصورة للزبون**. |
| نص المشاركة | يحتوي على العبارة الوحيدة **المرجو تحقق من المعلومات.** بدون ملخص طويل. |
| ملف المشاركة | يحتوي على صورة واحدة في `files`، وتم اختبار عدم إنشاء PDF أو رابط WhatsApp تلقائي لمسار الصورة. |
| سلامة البيانات | استُعملت كوموندات مؤقتة أثناء اختبار المتصفح ولم تُحفظ في `localStorage`. |

## الفحوص

تم تمرير `node --check app.js` بنجاح، وتم تمرير `quick_validate.py 3d-peintures-catalog-workflow` بنجاح. كما تم اختبار إنشاء الصورة مؤقتًا والتحقق من العنوان والرقم والعبارة والثمنين وسجل القسط، ثم اختبار زر إعادة الإرسال والتحقق من النص المرافق ووجود الملف.
