
# QA — Retours داخل تسجيل القسط

## البداية — 16/08/2026

تم تحميل النسخة الجديدة على واجهة الهاتف وظهرت نافذة التطبيق بشكل سليم. تمت إضافة قسم `الإرجاعات / Retours` داخل نموذج تسجيل قسط جديد، وفيه خانة كود المنتوج، عدد القطع، والمعاينة. سيتم الآن اختبار المسار الكامل ببيانات مؤقتة فقط، مع إرجاع الطلبات و`localStorage` إلى الحالة الأصلية بعد الاختبار.

## الاختبارات الناجحة

تم اختبار منتوج بكود `AC40` وثمن `30 DH` مع إرجاع `2` قطع. ظهرت المعاينة داخل نموذج القسط باسم المنتوج، الكود، الثمن، القطع المتوفرة، وقيمة `−60 DH`. بعد مسار الحفظ المؤقت، تسجل إرجاع واحد ونقص إجمالي البون والباقي بـ `60 DH`، ثم رجعت بيانات الطلبات و`localStorage` كما كانت.

تم اعتراض صورة العملية أثناء الحفظ، وظهرت فيها `الإرجاعات / Retours`، الكود، المبلغ `60,00`، واللون الأخضر. لم يتم حفظ بيانات الاختبار الحقيقية.
