# QA — خصم تغييرات الأثمنة وإرسال الصورة فقط

## النتيجة الوظيفية

أصبح فرق تغيير الثمن يُحسب حسب الوحدات المطلوبة في الكوموند. إذا تغيّر ثمن الوحدة من 6.00 إلى 5.00 وكانت الكمية 80 وحدة، يكون أثر العملية -80.00 DH، وينخفض إجمالي الكوموند من 1,920.00 إلى 1,840.00 DH. يبقى مجموع الأقساط كما هو، ويُعاد حساب الباقي من الإجمالي الجديد.

تمت إضافة `baseTotal` للكوموندات الجديدة لتفادي خصم التغيير أكثر من مرة. أما الكوموندات القديمة فتستعمل الإجمالي الحالي كقاعدة أولية ثم تعيد الحساب اعتمادًا على سجلات تغييرات الأثمنة.

## الاختبارات المنجزة

| الاختبار | النتيجة |
|---|---|
| فحص `app.js` | ناجح عبر `node --check app.js` |
| فحص `ai-agent-reports.js` | ناجح عبر `node --check ai-agent-reports.js` |
| حساب فرق الثمن حسب الكمية | ناجح: 6.00 → 5.00 × 80 = -80.00 DH |
| الإجمالي المعدل | ناجح: 1,920.00 → 1,840.00 DH |
| الباقي بعد 1,420.00 DH أداء | ناجح: 420.00 DH |
| تقرير AI العام | ناجح باختبار الفرق: التقرير زاد 1,840.00 وليس 1,920.00 |
| تفاصيل الكوموند | تعرض الإجمالي الجديد، مجموع الأقساط، الباقي، الثمن القديم والجديد، الكمية، وأثر التغيير |
| صورة العملية | ناجح؛ الصورة حافظت على اسم الزبون ورقم الكوموند والإجمالي الجديد ومجموع الأقساط والباقي والثمنين القديم والجديد |
| مشاركة الهاتف | ناجح؛ كائن المشاركة يحتوي `files` فقط، ولا يحتوي `text` أو رسالة WhatsApp |
| استرجاع البيانات | ناجح؛ كل الاختبارات استعملت كوموندًا مؤقتة ولم تُحفظ في localStorage |
