# QA — المساعد المبرمج بالدارجة المغربية

تم فحص النسخة المحلية بتاريخ 2026-08-15.

ظهر زر `مساعد 3D` في أسفل الشاشة، وفتحت نافذة المحادثة بشكل متجاوب ومناسب للهاتف. الواجهة والترحيب والأسئلة السريعة مكتوبة بالدارجة المغربية، وتظهر عبارة أن المساعد يعمل بلا API خارجي.

تم اختبار سؤال: `شحال ثمن AC40 ف 50 قطعة؟`، فتعرف المساعد على المنتوج والكود والكمية، وأعاد الثمن الصحيح حسب بيانات الكمية، ومعلومات العلبة والتوفر وباقي مستويات الأسعار.

تم اختبار سؤال: `شنو كاين فالسلة ديالي؟`، وبعد إصلاح أولوية المطابقة، أعاد المساعد جواب السلة الصحيح: السلة خاوية دابا، بدل عرض جواب عام عن المنتوجات.

تم فحص Console ولم تظهر أخطاء JavaScript، كما نجح `node --check app.js`. المساعد لا يرسل بيانات إلى خدمة خارجية؛ يقرأ المنتجات والسلة والطلبيات والزبناء من متغيرات التطبيق وlocalStorage الحالي.
