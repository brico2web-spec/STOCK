# QA — تغيير ثمن منتوج واحد فقط

| الاختبار | النتيجة |
|---|---|
| كوموند بمنتوجين | تم إنشاء اختبار مؤقت بمنتوج A ومنتوج B. |
| تغيير منتوج A | الثمن القديم 79.00 DH ظهر مشطوبًا، والثمن الجديد 70.00 DH ظهر في سطر A فقط. |
| مجموع منتوج A | أُعيد حسابه من 1,580.00 DH إلى 1,400.00 DH حسب فرق 9.00 DH × 20 قطعة. |
| منتوج B | بقي الثمن 75.00 DH والمجموع 2,250.00 DH بدون أي تغيير. |
| سبب الإصلاح | تم منع اعتبار القيم الفارغة للمعرف أو الكود أو الاسم تطابقًا عامًا مع جميع السطور. لا تتم المطابقة الآن إلا بمفتاح غير فارغ ومطابق. |
| سلامة البيانات | تم استعمال كوموند مؤقتة ولم تُحفظ في localStorage. |
| الفحص البرمجي | مرّ `node --check app.js` بنجاح. |
