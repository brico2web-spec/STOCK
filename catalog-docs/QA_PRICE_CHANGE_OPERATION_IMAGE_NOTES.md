# QA — عرض تغييرات الأثمنة وصورة العملية

## التغييرات
تمت إضافة قسم **تغييرات أثمنة المنتوجات** تحت سجل الأقساط داخل تفاصيل الكوموند، ويعرض اسم المنتوج والكود والثمن القديم والثمن الجديد والفرق والتاريخ.

تمت إضافة زر **إرسال صورة العملية** داخل نموذج تسجيل القسط. الصورة تتضمن اسم الزبون، رقم الكوموند، القسط الحالي، مجموع الأقساط، الباقي، وتفاصيل تغييرات الأثمنة. تتم المشاركة باستعمال مشاركة الهاتف عند توفرها، مع بديل تنزيل وفتح الصورة في WebView.

## الاختبارات

| الاختبار | النتيجة |
|---|---|
| `node --check app.js` | ناجح |
| `node --check ai-agent-reports.js` | ناجح |
| ظهور قسم تغييرات الأثمنة تحت سجل الأقساط | ناجح باختبار DOM مؤقت |
| ظهور المنتوج والثمن القديم والجديد والفرق | ناجح؛ ظهر 30.00 → 28.00 DH وفرق −2.00 DH |
| إنشاء صورة العملية | ناجح |
| نوع ملف الصورة | ناجح؛ JPEG |
| مشاركة الصورة | ناجح باختبار مشاركة وهمية؛ تم إنشاء ملف بحجم 127109 بايت تقريبًا |
| الحفاظ على بيانات المستخدم | ناجح؛ الاختبار استعمل بيانات مؤقتة في الذاكرة ولم يحفظها |
| زر الصورة داخل نموذج القسط | تمت إضافته وربطه بالدالة المناسبة |
| بديل WebView | تمت برمجته عبر تنزيل الصورة وفتحها في نافذة جديدة عند غياب مشاركة الملفات |
