# QA — JSON كامل بالصور

تم فحص النسخة المحلية بتاريخ 2026-08-14.

تظهر داخل قسم تحميل واستيراد الإدارة أربعة خيارات: النسخة الخفيفة JSON، رفع النسخة الخفيفة JSON، تحميل المنتجات والصور JSON، ورفع المنتجات والصور JSON. لم يعد زر `Restaurer archive Excel` ظاهرًا في القائمة.

فحص `node --check app.js` نجح، كما نجح التحقق من وجود `menuExportProductsFullJson` و`menuImportProductsFullJson` وعدم وجود `menuImportAllExcel` في HTML.

تم الضغط على زر تحميل المنتجات والصور JSON وظهر إشعار نجاح: `تم تحميل 0 منتوج(ات) مع الصور والمعلومات بصيغة JSON`. الملف الكامل يستخدم صيغة `3D_PEINTURES_PRODUCTS_IMAGES_JSON`، الإصدار 3، ويضم المنتجات مع Data URL للصور والمعلومات والأسعار والأقسام، إضافة إلى السلة والكوموندات والزبناء.
