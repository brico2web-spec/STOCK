# QA — إظهار أقسام الصورة حسب نوع العملية

## القواعد المطبقة

- صورة Bon de commande عند `paymentTermMode === "cod"` لا تعرض قسم سجل الأقساط، ولا مجموع الأقساط، ولا قسم تغييرات الأثمنة، ولا سطر الإجمالي قبل تغييرات الأثمنة.
- صورة Bon de commande ذات أجل محدد تعرض تنبيه آخر أجل للاستخلاص، وتعرض الأقسام الخاصة بالأقساط أو تغييرات الأثمنة فقط إذا كانت البيانات موجودة.
- صورة عملية القسط تعرض سجل الأقساط السابقة عندما تكون العملية قسطًا، وتعرض تغييرات الأثمنة فقط عندما توجد تغييرات فعلية.
- صورة تغيير الثمن فقط لا تعرض سجل القسط الحالي، لكنها تعرض تفاصيل تغييرات الأثمنة الفعلية.

## نتيجة الاختبار داخل التطبيق

بعد إعادة تحميل النسخة، تم اختبار القالب مباشرة عبر اعتراض مرحلة تحويل HTML إلى صورة:

| الحالة | النتيجة |
|---|---|
| عند الاستلام | لا يوجد سجل الأقساط، ولا مجموع الأقساط، ولا تغييرات الأثمنة؛ ظهر تنبيه `طريقة الاستخلاص: عند الاستلام`. |
| أجل محدد | ظهر تنبيه `آخر أجل للاستخلاص: التاريخ`. |
| صورة دفع قسط | ظهر `سجل الأقساط السابقة`، ولم يظهر قسم تغييرات الأثمنة عندما لا توجد تغييرات فعلية. |

كما اجتاز `app.js` فحص الصياغة بواسطة `node --check app.js`.
