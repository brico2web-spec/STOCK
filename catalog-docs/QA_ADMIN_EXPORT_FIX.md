# QA — إصلاح قائمة الإدارة وتحميل المنتجات والصور

| الاختبار | النتيجة |
|---|---|
| زر الأقساط في التسيير التجاري | تم حذفه من `index.html`. |
| زر تغيير الأثمنة في التسيير التجاري | تم حذفه من `index.html`. |
| مراجع JavaScript للزرين | تم حذفها من `app.js` حتى لا يحدث خطأ عند تحميل الصفحة. |
| زر تحميل المنتجات والصور | بقي ظاهرًا بالمعرف `menuExportProductsFullJson`. |
| طريقة التحميل | أصبحت الدالة `exportBackup` غير متزامنة ومحاطة بمسارات آمنة: مشاركة الملف عند دعم الهاتف، تنزيل محمي، ثم نافذة نصية أو نسخ للحافظة كبديل. |
| الصور | مازال ملف النسخة الكاملة يحتوي على `backupProductSnapshot(..., true)` للحفاظ على صور المنتجات والمعلومات. |
| الاختبار داخل المتصفح | اختفت الأزرار المحذوفة، ونجحت مشاركة ملف تجريبية بدون إغلاق الموقع. |
| الصياغة | اجتاز `app.js` فحص `node --check`. |
